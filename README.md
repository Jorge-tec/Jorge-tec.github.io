## 🏛️ Project Architecture

This application is built with vanilla, high-performance web standards (HTML5, Modern CSS3 Custom Properties, and ES Modules) using the **Kinetic Engineering** design system.

```text
.
├── index.html                  # Main production entry point
├── kinetic_engineering/        # Approved Design System specifications (DESIGN.md)
├── profile/                    # Canonical Source of Truth & Evidence documents
│   ├── README.md               # Documentation index & governance guide
│   ├── profile-model.md        # Synthesized Professional Profile Model
│   ├── identity.md             # Identity and positioning
│   ├── experience.md           # Professional history & client assignments
│   ├── skills.md               # Categorized technical competencies
│   ├── education.md            # Formal academic foundation (SENA ADSI)
│   ├── certifications.md       # Accredited corporate certifications
│   ├── learning.md             # Continuous training catalog (150+ completed units)
│   ├── recognitions.md         # Verbatim TCS Gems appreciation notes
│   └── sources.md              # Evidence provenance & privacy classifications
├── src/
│   ├── components/
│   │   └── App.js              # UI component rendering logic
│   ├── data/
│   │   └── profileData.js      # Structured data layer
│   ├── scripts/
│   │   └── main.js             # Application initialization
│   └── styles/
│       └── main.css            # Kinetic Engineering styles & tokens
└── package.json                # Local development tooling
```

## 🚀 Local Development

To run the application locally:

```bash
# Clone the repository
git clone https://github.com/Jorge-tec/Jorge-tec.github.io.git
cd Jorge-tec.github.io

# Start local static server
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.
